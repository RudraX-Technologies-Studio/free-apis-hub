## 🔍 Module Overviews

### 🤖 [Module 1: AI & LLM Inference](./ai-llm-apis.md)
Contains 10 conversational and plain-text generation gateways. Features direct cloud endpoints (Pollinations.AI, DuckDuckGo Instant Answer) and keyless self-hosted gateways (Ollama, vLLM, LocalAI) running standard OpenAI-compliant schemas without private credentials.

### 🎨 [Module 2: Image Generation & Media](./free-image-apis.md)
Indexes 10 image generation services and visual placeholder pipelines. Developers can integrate dynamic visual generation directly into HTML image tags without billing tokens.

### 👤 [Module 3: Avatars, Identity & Mock Datasets](./profile-mock-apis.md)
Provides 10 high-speed identity datasets and SVG avatar engines (DiceBear, RandomUser, DummyJSON) suitable for testing state management, frontend rendering, and user onboarding flows.

### 📚 [Module 4: NLP, Semantics & Knowledge Engines](./dictionary-and-nlp-apis.md)
Covers 10 computational linguistics endpoints, live encyclopedic summaries, lexical association tools, translation nodes, and trivia feeds accessible through standard GET calls.

### ⚙️ [Module 5: Audio, Sandboxed Code & Utilities](./audio-code-and-utility-apis.md)
Features 10 native utilities including web audio synthetics, sandboxed multi-language compilation engines (Piston), localized Whisper speech recognition, and high-accuracy weather feeds.
